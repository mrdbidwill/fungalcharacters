Fungal Characters

A free, publicly maintained list of the characters used to describe and identify fungi.

Characters are the features recorded when describing a fungus, such as Cap Width or Gill Attachment. For each one, this site gives its name and scientific name, definition, value type and, where there is a list to choose from, its value options. The goal is data that anyone can use and everyone can help maintain.

Where people disagree

Mycologists and collectors do not always agree on terms or on values. On fungalcharacters.org, each character and value option shows its source, and every change is kept in a public history that shows who changed what, when and why, so earlier wording is never lost. Ultimately, users decide which characters and values live on. Thanks on the Thanks page does not mean anyone named there endorses any value on the site.

Open tools and public data to improve the accuracy of fungal data.

No advice about consumption

fungalcharacters.org records how sources describe fungi. It is not a guide to eating, using or handling any fungus, and nothing here says whether any fungus is safe. Values about chemistry or toxicity are reported only as their source states them.
