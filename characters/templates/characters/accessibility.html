{% translate "What the site does" %}

  • {% translate "Large, clear text (Atkinson Hyperlegible, a typeface made for readers with low vision) and very high contrast, in light and dark mode." %}
  • {% translate "Everything works with the keyboard; a clear outline shows where you are." %}
  • {% translate "Every page is organised with headings, has a “Skip to content” link, and marks the current page in the menu." %}
  • {% translate "Tables have column headings; every form field has a label." %}
  • {% translate "The site follows your device's settings for text size, dark mode, higher contrast and reduced motion." %}
  • {% translate "The aim is the international standard WCAG 2.2, level AA, with the stricter AAA level for text contrast. Pages are checked with an automated tool after every change." %}

{% translate "Known limits" %}

  • {% translate "The administrator's own pages are not checked." %}
  • {% translate "Pages kept for their authors under Documents are shown exactly as they sent them." %}
  • {% translate "Other languages are only partly translated; untranslated text is in English." %}
  • {% translate "Testing with people who use screen readers has only just begun. Your reports help most." %}
